# 學習路線與版本選擇

## 發布狀態
正式伴讀版本尚未發布，目前不要把 main 分支當成已完成教材。

## 預定學習順序
1. 商品與 SKU、SQL 查詢。
2. 訂單、採購、收貨與庫存保留。
3. 付款模擬、出貨、取消、退貨與對帳。
4. 報表、索引、權限、遷移與還原。
5. 受控 AI 問答、文件檢索與補貨草稿。

## 發布後如何選版本
依書中註記取得同一個 Release tag，不混用不同版本的 SQL、資料檔和程式。發布說明須列出對應章節、驗證環境、安裝命令、限制及修正項目。首次使用應從虛構資料及隔離環境開始，不連正式資料庫。

## 本站不提供什麼
目前沒有正式線上商店、真實支付整合、完整會計功能或生產環境維運保證。安裝及操作指令會在實際發布範例並驗證後提供，不以尚未存在的命令引導讀者。
