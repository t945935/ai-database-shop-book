# AI 時代的資料庫實戰：讀者服務

《AI 時代的資料庫實戰：打造網路商店進銷存系統》配套資源。

作者：Happy eBook Authors　｜　出版社：Happy eBook

以「日常咖啡選物店」為案例，從商品、訂單、採購入庫、庫存保留、出貨與退貨，逐步學習 PostgreSQL 及受控 AI 應用。

書籍及伴讀系統正在開發。本儲存庫目前先提供讀者服務說明與回報入口，**尚未提供可下載的正式伴讀版本**。本機原型測試不代表正式教材或發布包已驗收。

## 預定提供
經驗證的章節範例、虛構測試資料、執行與重設步驟、已知限制，以及對應書籍版本的發行包。未完成項目不視為既有功能。

## 使用界線
這是教學用單店、單倉、單幣別系統，不是可直接上線的 ERP 或支付服務。不要輸入真實顧客資料、金流憑證或正式商店資料庫連線資訊。
